# ALTAR Comunidad Cristiana

[Ver la landing en GitHub Pages](https://hectorsalazar.github.io/altar/)

Este repositorio contiene los archivos de publicación de la landing de ALTAR. GitHub Pages sirve el sitio estático desde la raíz de la rama `main`.

El diseño de la landing se basa en Resonance, de Bestlooker, y usa la tipografía DM Sans bajo la licencia OFL incluida.
